# The console lists only connected administrations

The official catalogue contains every ministry on service-public.bj. Only a few are connected to the simulated X-Road (they can receive filings). Connecting another one is not a toggle: it needs a depositable procedure and an instruction rule, which this review does not add. Showing the rest in the super-admin selector (old A11) looked like a broken menu. The console therefore lists only connected administrations. The operator status page still reports who is connected.
